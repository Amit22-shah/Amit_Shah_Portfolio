## 🚀 Getting Started

### View the Portfolio

1. **Option 1:** Clone this repository
   ```bash
   git clone https://github.com/Amit22-shah/Amit_Shah_Portfolio.git
   cd Amit_Shah_Portfolio
   ```

2. **Option 2:** Open directly in browser
   - Simply open `index.html` in your web browser
   - No installation or build process required!

3. **Explore:** Navigate through the sidebar menu to explore projects, achievements, and academic records

### Browser Compatibility
- ✅ Chrome/Edge (v90+)
- ✅ Firefox (v88+)
- ✅ Safari (v14+)
- ✅ Mobile browsers (fully responsive)
